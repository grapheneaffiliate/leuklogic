Why trust this one

Your statement never leaves your machine. The PDF is read by this page's own JavaScript (a locally-hosted copy of Mozilla's pdf.js — the same engine Firefox uses). The only network activity this page ever has is loading its own code from this site; no request exists that carries your data anywhere. Watch the Network tab while you convert: nothing goes out.
