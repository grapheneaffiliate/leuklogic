ShrinkKit — compress files without uploading them

Drop files in, get a smaller file out. Documents, spreadsheets and text are zipped; images are re-encoded to a quality you choose. Everything happens inside this browser tab — nothing is sent anywhere, so it works with your Wi-Fi switched off.

Why that matters: most free compressors upload your file to a server to do the work. If the file is a bank statement, a client export, or an unreleased report, that is a copy you no longer control. This page makes zero network requests — open your browser's Network tab and watch it stay empty.
